# Project & Product Management Templates

Free, simple templates for software project and product managers. Copy them, change them, and use them with your own team. No sign-up, no cost.

I am Hashir Haider Khattak, a Project & Product Manager working on web, mobile and AI automation projects. I use these templates to take a project from the first client meeting to launch.

## What is inside

| File | Use it when |
| --- | --- |
| [`01-requirements-checklist.md`](01-requirements-checklist.md) | You finish a client call and want to be sure nothing is missing |
| [`02-user-story-template.md`](02-user-story-template.md) | You write features for developers |
| [`03-sprint-planning-checklist.md`](03-sprint-planning-checklist.md) | You prepare and run sprint planning |
| [`04-weekly-status-report.md`](04-weekly-status-report.md) | You update a client or manager every week |
| [`05-risk-register.md`](05-risk-register.md) | You want to track what could go wrong |
| [`06-retrospective-template.md`](06-retrospective-template.md) | You close a sprint and want to improve |

## How to use

1. Click **Use this template** on GitHub, or download the file you need.
2. Replace the text in `[square brackets]` with your own details.
3. Delete any section that does not fit your project.

## Contribute

Found a way to make a template better? Open an issue or a pull request. Short, practical changes are welcome.
